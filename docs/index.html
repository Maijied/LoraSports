Get Started

Install in 3 Steps

1
Download the Extension

Grab the latest .zip from the GitHub Releases page, or install directly from the Firefox Add-ons store once approved.

2
Open Firefox Debugging

Navigate to about:debugging → This Firefox → Load Temporary Add-on. Point it at manifest.json inside the extracted folder.

3
Click the ⚽ Icon

The Lorapok WorldCup 26 icon appears in your Firefox toolbar. Click it to open the Tactician's Logbook — all five panels are ready to go, no sign-in required.
